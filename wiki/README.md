# Battle Stations Wiki

This wiki gathers what is known about Battle Stations from the current Godot build,
the archived Unity project, surviving assets, and collaborator conversations. It is
the project's source of truth; uncertainty is called out instead of being presented
as settled design.

## Confidence labels

- **Implemented** — present in the active Godot code or scenes.
- **Archived** — present only in the Unity snapshot.
- **Documented** — supported by a surviving conversation or artifact.
- **Inferred** — suggested by names or assets, but not confirmed as design intent.
- **Proposed** — a future idea, not established canon.

## Keeping this wiki useful

When a mechanic changes, update the relevant wiki page in the same change. Include a
file link for implementation claims, keep proposals out of the implemented sections,
and add newly recovered source material to [History and sources](history-and-sources.md).
