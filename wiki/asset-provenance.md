# Asset Provenance and Release Gate

[Wiki home](README.md)

This register separates repository presence from permission to ship. An asset remains
**blocked** until its creator or rights holder, source, license, and allowed uses are
recorded in writing. Do not infer ownership from a filename or Discord upload.

| Asset family | Repository location | Current evidence | Release status | Required evidence |
|---|---|---|---|---|
| Architects Daughter font | `assets/fonts/ArchitectsDaughter-*` | Bundled OFL text | Reviewable | Confirm copyright notice is retained in credits/distribution |
| DkCoolCrayon font | `assets/fonts/DkCoolCrayon.ttf` | No license file found | Blocked | Identify source and obtain redistribution license |
| Board, train, spider, projectile, and UI art | `assets/sprites/`, `assets/the_new_*.png` | Project files and collaborator notes only | Blocked | Creator, ownership, and commercial/Web distribution permission |
| GAME OVER artwork | `assets/sprites/ui/GAME_OVER_TEXT.webp` | Supplied Discord attachment and design quote | Blocked | Creator and explicit distribution permission |
| Character portraits/dialogue art | root PNGs and `assets/sprites/ui/portrait/` | Project files only | Blocked | Creator and explicit distribution permission |
| Recorded music | `assets/audio/*.mp3`, `assets/audio/songs/` | Titles/files only; provenance unresolved | Blocked | Performer, composition/recording rights, license, and attribution |
| Recorded sound effects | `assets/audio/sfx/*.wav` | Files only | Blocked | Creator/source and license for every recording |
| Procedural UI cues | Generated by `scripts/audio_fx.gd` | Original runtime synthesis in this repository | Clear internally | Include as project code; no external recording attribution required |
| Archived Unity assets | `legacy_unity/` | Historical snapshot | Archive only | Review separately before copying anything into a release |

1. Ask Gubgub and each contributor to identify the creator of every active art/audio
   family and state whether commercial, browser, promotional, and derivative use is
   permitted.
2. Recover original source links and licenses for both fonts and every recording.
3. Decide whether `Train 45.mp3` and the other recordings are final, licensed music
   or placeholders; remove them from release exports if evidence remains unavailable.
4. Store written confirmations or license files in a future `legal/` directory and
   update this table from **Blocked** to the exact license/status.
5. Produce final credits only from that evidence.

Until those steps are completed, local testing is appropriate but a public release
must not be represented as rights-cleared.
